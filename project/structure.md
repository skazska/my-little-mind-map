# Project management Structure

- IDEA.md: initial project idea, vision, goals
- `project/`: project-management
  - project-flow.md: project flow guidelines, including planning, expectations gathering, decision making, and other project management practices.
  - PLAN.md: high-level project plan and roadmap
  - folders for each plan milestone
    - status (.md and folder)
    - results (.md and folder)
    - expectations (.md and folder)
    - decisions (.md and folder)
    - phases/sprints
      - tasks, issues, etc.
